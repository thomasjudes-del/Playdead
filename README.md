# The Glasshouse

Experimental browser game prototype exploring cinematic movement, atmosphere and environmental storytelling in a compact side-scrolling experience.

## What it includes

- Three.js scene rendered directly in the browser
- Touch and pointer controls for mobile and desktop
- Character movement, jumping, checkpoints and hazards
- Environmental lighting, fog, rain and scripted sequences
- Interactive lever and gate mechanics
- Responsive landscape-first presentation
- Lightweight single-file prototype for rapid iteration

## Why the project matters

The project demonstrates rapid interactive prototyping: translating a visual and narrative concept into a playable web experience, iterating on controls and browser compatibility, and using code to test atmosphere, pacing and interaction rather than treating the concept as a static mock-up.

## Stack

- HTML
- JavaScript
- Three.js
- WebGL
